# CareerSetu India 🇮🇳

An advanced, responsive Indian job portal built with **HTML5, CSS3 and Vanilla JavaScript**.

## Features
- Indian job listings with ₹ LPA salary ranges
- Company logos and featured companies
- Search by job title, skill and location
- Category, job-type and experience filters
- Pagination and sorting
- Save jobs with localStorage
- Candidate profile and application workflow
- Recruiter job posting workflow
- Login / signup UI
- Dark mode
- Responsive mobile/tablet/desktop design
- Fresher and internship focused opportunities
- Popular Indian hiring cities
- Career advice and contact pages

## Run locally
Open the project in VS Code and use **Live Server** on `index.html`.

## Tech stack
HTML5 · CSS3 · JavaScript · LocalStorage · Font Awesome
